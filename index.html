LANGKAH 1

Profil Lembaga, Kop & Tema Warna

Isi nama yayasan, kepala PAUD, operator, alamat, serta unggah logo yayasan dan logo sekolah. Anda juga dapat mengatur warna header dan banner dashboard agar otomatis tampil pada seluruh kop surat cetak.

LANGKAH 2

Buku Induk Murid & PPDB Online

Kelola data peserta didik per kelompok (A1–B3) atau impor massal lewat Template CSV. Calon murid di menu PPDB Online dapat diterima satu klik untuk otomatis masuk ke Buku Induk dan dicetak formulirnya.

LANGKAH 3

ID Card CR80 & Presensi Scan QR

Cetak kartu identitas murid/guru berstandar CR80 lengkap dengan QR Code & Barcode Code128. Di menu Presensi Harian, cukup scan kartu lewat kamera HP atau alat scanner untuk mencatat hadir + panggilan suara otomatis.

LANGKAH 4

Kurikulum Deep Learning & Transisi SD

Gunakan Bank 20 Tema Interaktif untuk menyalin prompt modul ajar ke AI atau memasukkannya langsung ke Prota/RPPH. Pantau kesiapan anak ke SD pada menu 6 Kemampuan Fondasi PAUD–SD dengan dropdown nama siswa.

LANGKAH 5

Kalender Akademik, Jadwal KBM & Sentra

Klik tanggal pada Kalender Akademik interaktif untuk menjadwalkan agenda. Atur Jadwal KBM & Sentra Main secara dinamis lengkap dengan pilihan Jam Mulai–Selesai, Kelas/Rombel, dan Guru Pengampu.

LANGKAH 6

Kepegawaian, Slip Gaji & Surat SK

Hitung gaji bersih PTK otomatis dengan rincian THR, BPJS Kesehatan/TK, serta potongan PPh 21 (otomatis terpotong di Buku Kas). Buat surat resmi di menu Surat & SK dengan dropdown penerima dan pilihan ukuran font (10pt–14pt).

LANGKAH 7

Buku Kas Umum, SPP & Tabungan Siswa

Pilih nama siswa lewat dropdown pada modul SPP, Tagihan, Tabungan & Beasiswa (nama wali otomatis terisi). Setiap transaksi SPP otomatis menambah pemasukan di Buku Kas Umum dan dapat dicetak kwitansinya atau dikirim PDF via WA.

LANGKAH 8

Mutu Akreditasi, Sarpras & Folder Galeri

Kelola kelengkapan 8 STPPA, 8 SNP, Akreditasi BAN-PDM, Sarpras & Buku Tamu. Pada menu Galeri Dokumentasi, buat folder album kegiatan khusus dan unggah foto kegiatan langsung dari perangkat Anda.

LANGKAH 9

Kirim PDF WA, HTML & Backup JSON

Gunakan menu Kirim Link & HTML untuk mengekspor laporan PDF resmi ke WhatsApp, membagikan file HTML Mode Baca (terkunci) ke wali murid/pengawas, file Master ke sesama guru, serta mencadangkan database .JSON.

💡 Tips Keamanan & Kelancaran Penggunaan Offline:
  • Seluruh perubahan data tersimpan otomatis di memori browser perangkat Anda (tanpa perlu koneksi internet).
  • Lakukan Backup Database (.JSON) atau unduh HTML Master secara rutin setiap pekan/bulan sebelum menghapus cache browser atau berganti perangkat.
  • Gunakan tombol 🖨 Cetak di pojok kanan atas untuk mencetak seluruh halaman aktif, atau klik 🖨 Cetak / 💬 PDF WA di kolom Aksi tabel untuk mencetak/mengirim dokumen satuan.

Kirim File HTML, Sinkronisasi & Backup Database

Bagikan aplikasi mandiri berisi seluruh data lembaga dalam mode terkunci (Read-Only untuk wali murid/pengawas) atau mode Master (untuk sesama guru/operator), serta cadangkan database JSON.

📎 File Siap Dilampirkan:

🔒 MODE BACA (READ-ONLY)

Laporan Digital Terkunci (Wali Murid / Yayasan / Dinas)

Seluruh formulir input, tombol hapus, dan menu pengaturan disembunyikan otomatis. Penerima hanya dapat melihat data, mencari informasi, dan mencetak dokumen tanpa bisa mengubah isi database.

✏️ MODE MASTER (DAPAT DIEDIT)

File Kerja & Database Penuh (Sesama Guru / Operator)

Mengemas seluruh database lembaga terbaru ke dalam satu file HTML Master agar guru kelompok atau operator lain dapat melanjutkan pengisian data pada perangkat mereka.

⚡ Kirim Cepat File Master ke Wali Kelompok:
📄 EKSPOR & KIRIM PDF WHATSAPP

Kirim File Laporan PDF Resmi Lewat WhatsApp

Pilih jenis laporan lembaga, sistem akan otomatis membuat file PDF berkop resmi dan membukanya ke WhatsApp tujuan di atas.

CADANGAN DATA MENTAH (JSON)

Backup & Restore Database JSON

Unduh cadangan seluruh data aplikasi ke dalam satu file .json atau pulihkan kembali data dari file cadangan sebelumnya.
